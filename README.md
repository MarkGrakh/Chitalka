# Читательский навигатор

Веб-сервис для подбора книг из фонда библиотеки по фото обложки, настроению, описанию или голосу. Плюс — читательская траектория и аналитика для библиотекаря.

## Возможности

**Для читателя (гостя):**
- Поиск книг по текстовому запросу (семантический поиск с учётом синонимов).
- Поиск по фотографии обложки (OCR через Tesseract.js).
- Голосовой ввод через Web Speech API.
- Персональная читательская траектория с рекомендациями на «развилках».

**Для библиотекаря:**
- Авторизация по логину и паролю.
- Дашборд с аналитикой: топ-тем, «провальные» запросы, динамика по дням.
- Экспорт «провальных» запросов в CSV.

## Демо-доступ библиотекаря

- **Логин:** `admin`
- **Пароль:** `library2026`

## Технологии

- HTML5 + CSS3 + JavaScript (ES6+).
- Без Node.js, без сборщиков, без фреймворков.
- Tesseract.js (OCR) и Chart.js (графики) подключаются через CDN.
- Данные хранятся в `localStorage` браузера.
- Хостинг — GitHub Pages.

## ИИ-помощник (опционально)

Сервис поддерживает опциональное улучшение поиска через **YandexGPT**.
По умолчанию ИИ **выключен** — работает только базовый TF-IDF-поиск.

### Что делает ИИ

1. **Переранжирование результатов.** После TF-IDF-поиска ИИ получает
   топ-15 книг и запрос читателя, а затем возвращает 8 наиболее
   подходящих по смыслу.
2. **Расширение запроса синонимами.** ИИ предлагает связанные темы
   для более полного поиска.
3. **Объяснение рекомендаций на «развилках».** Вместо шаблонной фразы
   ИИ генерирует живое объяснение, почему читателю будет интересна
   смежная тема.

### Как включить

1. Получите **API-ключ** и **folder_id** в Yandex Cloud:
   https://cloud.yandex.ru/docs/foundation-models/quickstart
2. Откройте сайт, нажмите кнопку **⚙️** в шапке.
3. Введите API-ключ и folder_id.
4. Поставьте галочку «Включить ИИ-помощник».
5. Нажмите **«Проверить»**, чтобы убедиться в работоспособности.
6. Нажмите **«Сохранить»**.

Настройки сохраняются **только в вашем браузере** (localStorage)
и не передаются на сервер.

### ⚠️ Ограничение безопасности

При размещении на GitHub Pages **API-ключ виден в исходном коде
и в инструментах разработчика браузера**. Это допустимо только
для демонстрации и прототипа.

**Для продакшена** вызовы ИИ нужно вынести на серверный прокси:
- **Cloudflare Workers** — бесплатно, поддерживает JavaScript;
- **Deno Deploy** — бесплатно, тоже JavaScript.

### Стоимость

YandexGPT-lite на момент написания: около 0,20 ₽ за 1000 токенов.
Один поисковый запрос с переранжированием — примерно 1500–2000 токенов,
то есть менее 1 рубля за запрос. Для демонстрации — копейки.
